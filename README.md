# 🛒 Carrinho de Compras com JavaScript
### 📌 Sobre o Projeto

Este projeto consiste no desenvolvimento de um carrinho de compras interativo, utilizando JavaScript, com foco na prática de lógica de programação e manipulação do DOM.

### 🚀 Tecnologias Utilizadas  

HTML5  
CSS3  
JavaScript  
🎯 Objetivo

## Desenvolver uma interface web funcional que permita:

Adicionar produtos ao carrinho
Atualizar a quantidade de itens
Remover produtos
Atualizar o carrinho dinamicamente  

⚙️ Funcionalidades  
➕ Adicionar produtos ao carrinho  
🔢 Atualizar quantidade automaticamente  
❌ Remover produtos  
🧹 Remoção automática ao chegar em zero  
🔄 Atualização dinâmica na tela (DOM)  
📂 Estrutura do Projeto

├── index.html

├── script.js
